# Project Overview — Scholarship Tracking System

## 1. ชื่อโครงงาน
**ระบบติดตามทุนการศึกษา (Scholarship Tracking System)**

## 2. ปัญหาและที่มา
กระบวนการจัดการทุนการศึกษามีผู้เกี่ยวข้องหลายกลุ่ม เช่น นักศึกษา เจ้าหน้าที่ทุน และคณะกรรมการ หากข้อมูลประกาศทุน การสมัคร เอกสาร การพิจารณา ผลทุน และการติดตามหลังได้รับทุนกระจายอยู่หลายช่องทาง อาจทำให้การติดตามสถานะและการสรุปข้อมูลทำได้ยาก

ระบบนี้จึงมีเป้าหมายเพื่อรวมกระบวนการสำคัญไว้ในระบบเดียว โดยเริ่มจากการจัดการทุน ไปจนถึงการสมัคร พิจารณา ประกาศผล และติดตามผู้ได้รับทุน

## 3. วัตถุประสงค์
- จัดการข้อมูลทุนการศึกษาและประกาศทุน
- ให้นักศึกษาค้นหาและสมัครทุน
- รองรับการส่งและตรวจสอบเอกสารประกอบ
- รองรับการตรวจสอบคุณสมบัติและการพิจารณา
- บันทึกผลการประเมินและผลทุน
- ติดตามผู้ได้รับทุนหลังประกาศผล
- สนับสนุน Dashboard รายงาน และการแจ้งเตือน

## 4. กลุ่มผู้ใช้งานหลัก
| ผู้ใช้งาน | บทบาทหลัก |
|---|---|
| Student | ค้นหา สมัคร ส่งเอกสาร และติดตามสถานะทุน |
| Scholarship Officer | จัดการทุน ตรวจสอบใบสมัครและเอกสาร |
| Committee | พิจารณาและประเมินผู้สมัคร |
| Administrator | จัดการผู้ใช้และสิทธิ์การใช้งาน |

## 6. พื้นที่งานหลัก 6 โมดูล
- **M01 User & Student Management** — ผู้ใช้และข้อมูลนักศึกษา
- **M02 Scholarship Management** — การจัดการทุนและประกาศทุน
- **M03 Application & Document Management** — การสมัครและเอกสาร
- **M04 Scholarship Review & Evaluation** — ตรวจสอบและประเมิน
- **M05 Award & Follow-up Management** — ผลทุนและการติดตาม
- **M06 Dashboard, Report & Notification** — Dashboard รายงาน และการแจ้งเตือน

รายละเอียดของแต่ละพื้นที่งานอยู่ใน `05_team_feature_allocation.md`
