## Scope Boundary

### ระบบต้องรองรับ
- การจัดการข้อมูลทุน
- การสมัครทุน
- การตรวจสอบ
- การพิจารณา
- การประกาศผล
- การติดตามผู้ได้รับทุน

### ระบบไม่จำเป็นต้องรองรับในระยะนี้
- การจ่ายเงินโดยตรง
- การเชื่อมต่อธนาคาร
- การประมวลผลเอกสารด้วย AI
- ระบบภายนอกที่ไม่ได้กำหนด
- Application แยกสำหรับ Mobile

## Definition of Done — Scope Level
Feature ถือว่ามีขอบเขตชัดเจนเมื่อสามารถระบุได้ว่า
- ใครเป็นผู้ใช้งาน
- Feature ทำอะไร
- Feature เกี่ยวข้องกับ Module ใด
- ข้อมูลอะไรที่เกี่ยวข้อง
- ผลลัพธ์คืออะไร
- มีข้อจำกัดอะไร
- มีความสัมพันธ์กับ Module อื่นอย่างไร
