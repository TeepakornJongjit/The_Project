# Updated Use Case — ระบบติดตามทุนการศึกษา

## 1. Actors

- **Visitor** — นักศึกษาที่ยังไม่มีข้อมูลในระบบ สามารถสมัครสมาชิกและดูทุนที่เผยแพร่ได้
- **Student** — นักศึกษาที่มีบัญชีและโปรไฟล์ในระบบ
- **Scholarship Officer** — จัดการทุน ตรวจสอบใบสมัคร/เอกสาร และดำเนินการประกาศผล
- **Committee** — กรรมการที่ได้รับมอบหมายให้ประเมินใบสมัคร
- **Accounting Staff** — ดำเนินการด้านการโอนเงินทุน
- **Admin** — จัดการผู้ใช้ บทบาท สิทธิ์ และ Audit Log
- **Email Service** — ระบบภายนอกสำหรับส่งการแจ้งเตือนทางอีเมล

## 2. Use Case ที่ปรับปรุง

### Visitor
1. สมัครสมาชิก
2. ดูทุนที่เผยแพร่
3. ค้นหาทุน
4. เข้าสู่ระบบ
5. รีเซ็ตรหัสผ่าน

### Student
1. จัดการโปรไฟล์นักศึกษา
2. กรอกใบสมัครทุน
3. บันทึกใบสมัครแบบร่าง
4. แนบเอกสาร
5. ส่งใบสมัคร
6. ติดตามสถานะใบสมัคร
7. แก้ไข/ส่งเอกสารใหม่ตามคำร้องขอ
8. ดูผลการสมัคร
9. ดู/ติดตามรายการ Follow-up ของตน

### Scholarship Officer
1. จัดการข้อมูลทุน
2. จัดการเงื่อนไขทุน
3. จัดการเอกสารที่ต้องใช้
4. เปิด/ปิดรับสมัคร
5. ตรวจสอบคุณสมบัติ
6. ตรวจสอบเอกสาร
7. ขอแก้ไข/ส่งเอกสารใหม่
8. มอบหมายกรรมการ
9. สรุปผลการพิจารณา
10. ประกาศผล
11. ส่งการแจ้งเตือน
12. บันทึก/ติดตามการโอนเงิน
13. จัดการ Follow-up ผู้ได้รับทุน

### Committee
1. ดูใบสมัครที่ได้รับมอบหมาย
2. ประเมินใบสมัคร
3. บันทึกความคิดเห็น
4. ดูผลประกาศทุนของใบสมัครที่ตนเองประเมิน

### Accounting Staff
1. ดูรายการที่ได้รับอนุมัติให้จ่าย
2. บันทึกการโอนเงิน
3. บันทึกเลขอ้างอิงการโอน
4. ติดตามสถานะการจ่ายเงิน

### Admin
1. จัดการผู้ใช้
2. จัดการบทบาท
3. จัดการสิทธิ์
4. จัดการข้อมูลพื้นฐาน
5. ตรวจสอบ Audit Log
