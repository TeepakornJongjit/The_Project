# System Rules and Acceptance
## ระบบติดตามทุนการศึกษา

# 1. Application Rules
### Rule AR-01
นักศึกษาต้องมีบัญชีผู้ใช้งานก่อนสมัครทุน

### Rule AR-02
นักศึกษาสามารถสมัครเฉพาะทุนที่เปิดรับสมัครอยู่

### Rule AR-03
นักศึกษาต้องมีข้อมูลที่จำเป็นครบก่อนส่งใบสมัคร

### Rule AR-04
นักศึกษาต้องส่งเอกสารตามที่ทุนกำหนด

### Rule AR-05
ใบสมัครที่ส่งแล้วต้องมีสถานะเพื่อให้สามารถติดตามได้

# 2. Review Rules
### Rule RV-01
ใบสมัครต้องผ่านการตรวจสอบก่อนเข้าสู่การพิจารณา

### Rule RV-02
เอกสารที่ไม่ครบต้องสามารถระบุสถานะได้

### Rule RV-03
การประเมินต้องสามารถระบุผู้ประเมินได้

### Rule RV-04
ผลการประเมินต้องมีข้อมูลประกอบการพิจารณา

# 3. Result Rules
### Rule RS-01
ผลการพิจารณาต้องถูกยืนยันก่อนประกาศผล

### Rule RS-02
นักศึกษาสามารถดูผลของใบสมัครของตนเองได้

### Rule RS-03
นักศึกษาไม่สามารถเข้าถึงข้อมูลส่วนตัวของผู้สมัครรายอื่น

# 4. Follow-up Rules
### Rule FU-01
ผู้ได้รับทุนต้องมีข้อมูลสถานะการได้รับทุน

### Rule FU-02
ระบบต้องสามารถบันทึกผลการติดตาม

### Rule FU-03
ข้อมูลการติดตามต้องเชื่อมโยงกับทุนที่ได้รับ

# 5. Acceptance Criteria

## AC-01 — สมัครทุน
**Given** นักศึกษามีบัญชีและข้อมูลครบ

**When** นักศึกษาเลือกทุนที่เปิดรับและส่งใบสมัคร

**Then** ระบบต้องบันทึกใบสมัครและแสดงสถานะใบสมัคร

## AC-02 — ตรวจสอบเอกสาร
**Given** มีใบสมัครที่ส่งเข้ามา

**When** เจ้าหน้าที่ตรวจสอบเอกสาร

**Then** สามารถระบุได้ว่าเอกสารครบหรือมีเอกสารที่ต้องแก้ไข

## AC-03 — พิจารณาทุน
**Given** ใบสมัครผ่านการตรวจสอบ

**When** คณะกรรมการประเมินผู้สมัคร

**Then** ระบบต้องสามารถบันทึกคะแนนและความคิดเห็นได้

## AC-04 — ประกาศผล
**Given** มีผลการพิจารณาที่ได้รับการยืนยัน

**When** เจ้าหน้าที่ประกาศผล

**Then** นักศึกษาต้องสามารถตรวจสอบผลของตนเองได้

## AC-05 — ติดตามทุน
**Given** นักศึกษาได้รับทุน

**When** เจ้าหน้าที่ดำเนินการติดตาม

**Then** ระบบต้องสามารถบันทึกสถานะและผลการติดตามได้
