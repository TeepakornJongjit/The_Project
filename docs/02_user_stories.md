# User Stories
## ระบบติดตามทุนการศึกษา

## 1. Student
### US-ST-01 — จัดการบัญชี
> ในฐานะนักศึกษา ฉันต้องการจัดการบัญชีของตนเอง เพื่อให้สามารถใช้งานระบบได้

### US-ST-02 — จัดการข้อมูลส่วนตัว
> ในฐานะนักศึกษา ฉันต้องการจัดการข้อมูลส่วนตัวและข้อมูลการศึกษา เพื่อใช้ประกอบการสมัครทุน

### US-ST-03 — ค้นหาทุน
> ในฐานะนักศึกษา ฉันต้องการค้นหาและกรองทุนการศึกษา เพื่อค้นหาทุนที่เหมาะสมกับตนเอง

### US-ST-04 — ดูรายละเอียดทุน
> ในฐานะนักศึกษา ฉันต้องการดูรายละเอียดและคุณสมบัติของทุน เพื่อประเมินว่าตนเองสามารถสมัครได้หรือไม่

### US-ST-05 — สมัครทุน
> ในฐานะนักศึกษา ฉันต้องการสมัครทุนผ่านระบบ เพื่อส่งข้อมูลเข้าสู่กระบวนการพิจารณา

### US-ST-06 — ส่งเอกสาร
> ในฐานะนักศึกษา ฉันต้องการส่งเอกสารประกอบการสมัคร เพื่อใช้ในการตรวจสอบคุณสมบัติ

### US-ST-07 — ติดตามสถานะ
> ในฐานะนักศึกษา ฉันต้องการติดตามสถานะใบสมัคร เพื่อทราบความคืบหน้าของการสมัคร

### US-ST-08 — ดูผลการพิจารณา
> ในฐานะนักศึกษา ฉันต้องการดูผลการพิจารณาทุน เพื่อทราบว่าตนเองได้รับทุนหรือไม่

### US-ST-09 — ติดตามทุนที่ได้รับ
> ในฐานะนักศึกษา ฉันต้องการดูสถานะการได้รับทุนและเงื่อนไขหลังได้รับทุน

## 2. Scholarship Officer
### US-OFF-01 — จัดการทุน
> ในฐานะเจ้าหน้าที่ทุน ฉันต้องการสร้างและแก้ไขข้อมูลทุน เพื่อให้ข้อมูลทุนเป็นปัจจุบัน

### US-OFF-02 — กำหนดคุณสมบัติ
> ในฐานะเจ้าหน้าที่ทุน ฉันต้องการกำหนดคุณสมบัติและเงื่อนไขของทุน เพื่อให้ผู้สมัครทราบข้อกำหนด

### US-OFF-03 — จัดการช่วงเวลารับสมัคร
> ในฐานะเจ้าหน้าที่ทุน ฉันต้องการกำหนดช่วงเวลารับสมัคร เพื่อควบคุมระยะเวลาของการสมัคร

### US-OFF-04 — ตรวจสอบใบสมัคร
> ในฐานะเจ้าหน้าที่ทุน ฉันต้องการตรวจสอบใบสมัครและเอกสาร เพื่อคัดกรองผู้สมัครเบื้องต้น

### US-OFF-05 — ส่งต่อการพิจารณา
> ในฐานะเจ้าหน้าที่ทุน ฉันต้องการส่งผู้สมัครที่ผ่านการตรวจสอบเข้าสู่กระบวนการพิจารณา

## 3. Committee
### US-COM-01 — ดูผู้สมัคร
> ในฐานะคณะกรรมการ ฉันต้องการดูข้อมูลผู้สมัคร เพื่อใช้ประกอบการพิจารณา

### US-COM-02 — ประเมินผู้สมัคร
> ในฐานะคณะกรรมการ ฉันต้องการให้คะแนนและความคิดเห็น เพื่อใช้ในการตัดสินผล

### US-COM-03 — บันทึกผลการพิจารณา
> ในฐานะคณะกรรมการ ฉันต้องการบันทึกผลการพิจารณา เพื่อให้มีข้อมูลสำหรับการสรุปผล

## 4. Administrator
### US-ADM-01 — จัดการผู้ใช้งาน
> ในฐานะผู้ดูแลระบบ ฉันต้องการจัดการบัญชีผู้ใช้งาน เพื่อควบคุมการเข้าถึงระบบ

### US-ADM-02 — จัดการสิทธิ์
> ในฐานะผู้ดูแลระบบ ฉันต้องการกำหนดบทบาทและสิทธิ์ เพื่อให้ผู้ใช้งานแต่ละประเภทเข้าถึงข้อมูลที่เหมาะสม

## หลักการ
User Story ใช้สำหรับอธิบายความต้องการของผู้ใช้งานในระดับระบบ ยังไม่กำหนดวิธี implement หรือเทคโนโลยี
