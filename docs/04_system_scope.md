# System Scope
## ระบบติดตามทุนการศึกษา

## In Scope

### User Management
- การจัดการบัญชี
- การจัดการข้อมูลผู้ใช้งาน
- การจัดการบทบาท

### Student Management
- ข้อมูลนักศึกษา
- ข้อมูลการศึกษา
- ข้อมูลติดต่อ

### Scholarship Management
- ข้อมูลทุน
- ประกาศทุน
- คุณสมบัติ
- เงื่อนไข
- ระยะเวลารับสมัคร

### Application Management
- การสมัครทุน
- ใบสมัคร
- เอกสาร
- สถานะใบสมัคร

### Evaluation
- การตรวจสอบคุณสมบัติ
- การตรวจสอบเอกสาร
- การประเมิน
- คะแนน
- ความคิดเห็น
- ผลการพิจารณา

### Award Follow-up
- ประกาศผล
- ข้อมูลผู้ได้รับทุน
- การติดตาม
- เงื่อนไขหลังได้รับทุน

### Dashboard & Report
- ข้อมูลสรุป
- สถิติ
- รายงาน

### Notification
- แจ้งเตือนสถานะ
- แจ้งเตือนกำหนดการสำคัญ

## Out of Scope
- ระบบโอนเงินอัตโนมัติ
- การเชื่อมต่อระบบธนาคาร
- การเชื่อมต่อระบบการเงินของมหาวิทยาลัย
- Mobile Application แยกจากระบบหลัก
- AI สำหรับคัดเลือกผู้รับทุน
- OCR สำหรับอ่านเอกสาร
- Blockchain
- ระบบวิเคราะห์เชิงคาดการณ์
- การเชื่อมต่อบริการภายนอกที่ไม่ได้ระบุไว้
- รายละเอียด Source Code
- รายละเอียด Database Implementation
- รายละเอียด Infrastructure

## Scope Principle
หาก Feature ใหม่ไม่ได้สนับสนุนกระบวนการหลักของการจัดการและติดตามทุนการศึกษา จะถือว่ายังไม่อยู่ในขอบเขตจนกว่าทีมจะมีการตกลงเพิ่มเติม

การเพิ่ม Feature ใหม่ควรถูกบันทึกไว้ใน `10_team_decisions.md`
