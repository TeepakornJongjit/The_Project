# Development Roadmap
## ระบบติดตามทุนการศึกษา

เอกสารนี้กำหนดลำดับของการดำเนินโครงการในระดับภาพรวม

## Phase 1 — Requirement
- กำหนดปัญหา
- กำหนดวัตถุประสงค์
- ระบุผู้ใช้งาน
- ระบุ User Stories
- กำหนดขอบเขต

## Phase 2 — System Scope
- แบ่ง Module
- กำหนด Feature
- กำหนดข้อมูลหลัก
- กำหนดกระบวนการ
- กำหนด In Scope / Out of Scope

## Phase 3 — Team Allocation
- สมาชิก 6 คนเลือก Module
- กำหนดผู้รับผิดชอบ
- ตรวจสอบความสมดุลของงาน
- กำหนดจุดเชื่อมต่อระหว่าง Module

## Phase 4 — System Design
จึงเริ่มพิจารณารายละเอียดเชิงเทคนิค เช่น Architecture, Database Design, API, Interface และ Technology

รายละเอียดดังกล่าวยังไม่รวมอยู่ในเอกสาร Scope ระยะปัจจุบัน

## Phase 5 — Development
- พัฒนา Feature
- เชื่อมต่อ Module
- ทดสอบ Feature
- แก้ไขปัญหา

## Phase 6 — Integration & Testing
- Integration Test
- System Test
- ตรวจสอบ User Flow
- ตรวจสอบ Acceptance Criteria

## Phase 7 — Release
- เตรียมระบบ
- ตรวจสอบความพร้อม
- Release
- Documentation Update

## Current Phase
> **Phase 1–3: Requirement / Scope / Team Allocation**
